*   This restores the **Fractal Scaling Law**.

## 3. Decoupling: Context vs. Execution

A critical distinction in the system architecture:

### Context (Instant)
**Fractals & Royal Flush** logic uses **ALL Valid Zones**, regardless of age.
*   *Example:* A fresh H4 zone (Age 2) **IS** counted as a parent for an M5 zone.
*   *Why:* The "Context" must be real-time. If a massive wall appears, we respect it immediately for hierarchy.

### Execution (Patient)
**Trade Signals** apply the **Age Filter**.
*   *Example:* Even if we have a Royal Flush, we do not fire the trade until the Entry Zone (e.g., M5) crosses the **22 Bar** threshold.
*   *Why:* We wait for the specific entry structure to stabilize (leave the Toxic Phase) before risking capital.
