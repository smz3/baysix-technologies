## 2. The Symmetric Recursive Handshake

V5.9 enforces a **Chain of Trust**. A Sniper does not check the General; it only trusts its immediate Officer. The logic is perfectly symmetric across tiers:

### Level 1: Anchor Mode (The Initial Handshake)
- **Condition**: Parent timeframe just touched a zone (Initial Bounce).
- **Rule**: Child MUST be **Fresh + Nested** within Parent.
- **Goal**: "Falling Knife" Protection. Ensures the bridge is forming *inside* the macro level.

### Level 2: Free Flow Mode (Structural Liberation)
- **Condition**: Parent timeframe has reached its "Successor" (Outpost) and is Liberated.
- **Rule**: Child MUST be **Fresh**. Nesting is no longer required (Free Flow).
- **Goal**: Trend Maximization. Allows the structure to expand without spatial restriction.
